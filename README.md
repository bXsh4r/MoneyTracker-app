# App description
An android app that lets you track your money in IQD, and save it all in your local database for you to view it anytime you want.

The app is simple. but it doesn't have to remain like this. New features could be added to make it even more practical.

## Features
Currently the app let's you track how much money you have by displaying in the homescreen, you can make operations such as adding or removing money that directly affect the total amount,
and adding a description about how this money was added or removed. ALl that will be saved in a local database in your device. And you'll be able to view it all in the history part of the app.
The history shows you the money you added or removed (the operation and the amount), also the description you added, and the date and time when this value was inserted in the database.
