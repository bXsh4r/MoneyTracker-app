## Features
Currently the app let's you track how much money you have by displaying it in the homescreen, you can make operations such as adding or removing money that directly affect the total amount,
and adding a description describing how this money was gained or spent. A spinner is used to make this step easier, allowing the user to add custom descriptions to the spinner, and choosing them anytime instead of writing the description manually. All that will be saved in a local database on your device. And you'll be able to view it all in the history part of the app. Also a search bad was implemented to allow searching for items in the database. And by pressing the search button on the user's keyboard. They can view the total amount spent and gained from the results. Each history item shows you the money you added or removed (the operation and the amount), also the description you added, and the date and time when this value was inserted in the database.
